Interfaz de Usuario (React + Tailwind CSS):

   Diseño Mobile-First y Responsive.

   <WeeklyScheduler/>: Tabla/Grid interactiva para gestionar bloques libres y ventana de sueño.

   <TimezoneSelector/>: Selector con autodetección de zona horaria del dispositivo del usuario (ej. Europe/Madrid, America/Caracas).

   <GroupManager/>: Vista para gestionar participantes de una reunión.  
   
   <MeetingResultsList/>: Tarjetas con las múltiples opciones de horario convertidas a la hora local del usuario conectado.
